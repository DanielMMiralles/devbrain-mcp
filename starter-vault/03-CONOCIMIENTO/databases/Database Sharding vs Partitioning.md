# Database Sharding vs Partitioning
Estrategias de escalado horizontal:
- **Particionamiento**: División de una tabla grande en subtablas más pequeñas dentro de la misma instancia de [[PostgreSQL]].
- **Sharding**: Distribución de fragmentos de datos a lo largo de múltiples nodos o servidores de base de datos independientes.
