# Redis

## Resumen
Almacén de estructura de datos en memoria utilizado como base de datos de baja latencia, caché distribuida, broker de mensajes (Pub/Sub) y gestor de sesiones.

## Casos de Uso con tu Stack
- **Caché de consultas**: Acelerar lecturas complejas de [[PostgreSQL]] en [[FastAPI]] y [[NestJS]].
- **Rate Limiting**: Control de flujo en endpoints críticos.
- **Checkpoints rápidos para Agentes**: Almacenar estados transitorios de [[LangGraph]].
