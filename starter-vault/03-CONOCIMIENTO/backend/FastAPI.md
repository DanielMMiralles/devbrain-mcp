# FastAPI

## Resumen
Framework web moderno y rápido para construir APIs con Python 3.8+ basado en tipos estándar de Python y Pydantic.

## Cuándo usar
- Microservicios de alto rendimiento, backends para sistemas de IA y agentes ([[LangGraph]]), y servicios asíncronos.
