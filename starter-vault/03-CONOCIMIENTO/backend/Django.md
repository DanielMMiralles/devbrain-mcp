# Django

## Resumen
Framework web Python de alto nivel que fomenta el desarrollo rápido y el diseño limpio y pragmático ('batteries-included').

## Cuándo usar
- Aplicaciones web completas, paneles administrativos listos para producción y modelos de datos relacionales tradicionales.
