# NestJS

## Resumen
Framework progresivo de Node.js en TypeScript, fuertemente inspirado en Angular. Ofrece arquitectura modular out-of-the-box con inyección de dependencias.

## Cuándo usar
- Sistemas empresariales, APIs REST y microservicios complejos donde se requiere consistencia estricta de equipo.
