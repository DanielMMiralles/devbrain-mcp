# KV Caching in LLM Inference
Técnica de optimización en la inferencia autorregresiva de Transformers que almacena en memoria los tensores de Key y Value calculados en pasos anteriores, evitando recomputar el contexto en cada nuevo token generado. Se conecta con [[Prompt Caching & Context Windows]].
