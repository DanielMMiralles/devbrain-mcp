# Ollama

## ¿Qué es?
Herramienta que permite ejecutar modelos de lenguaje grandes (LLMs) localmente en tu propia máquina (Llama 3, Mistral, DeepSeek, Qwen) mediante una API REST sencilla.

## Integración con el Stack
- Permite generar embeddings locales para [[PostgreSQL]] / [[pgvector]] o correr agentes con [[LangGraph]] sin costo de API en entornos de desarrollo y pruebas.
