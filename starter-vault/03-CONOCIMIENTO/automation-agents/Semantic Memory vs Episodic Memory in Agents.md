# Semantic Memory vs Episodic Memory in Agents
Sistemas de memoria para arquitecturas agenticas:
- **Memoria Semántica**: Conocimiento factual recuperado vía embeddings y [[pgvector]].
- **Memoria Episódica**: Registro cronológico de interacciones y decisiones pasadas guardado en bases de datos o vaults como DevBrain.
