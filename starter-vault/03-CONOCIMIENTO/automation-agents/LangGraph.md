# LangGraph

## Resumen
Biblioteca para orquestar y controlar flujos de agentes y sistemas multi-agente con ciclos y control de estado persistente.

## Cuándo usar
- Flujos cognitivos complejos donde los agentes necesitan evaluar, retroalimentarse y tomar decisiones iterativas.
