# LiteLLM

## ¿Qué es?
Biblioteca y proxy I/O que unifica más de 100 proveedores de LLMs (OpenAI, Anthropic, Gemini, [[Ollama]], Bedrock) bajo la especificación estándar de la API de OpenAI.

## Ventajas
- Permite cambiar de proveedor o configurar fallbacks automáticos en servicios construidos con [[FastAPI]] o [[NestJS]] sin modificar la lógica de negocio.
