# Tailwind CSS

## Resumen
Framework CSS utility-first que permite diseñar interfaces completas directamente en el markup sin escribir CSS tradicional.

## Buenas Prácticas
- Usar clsx y 	ailwind-merge para clases dinámicas libres de colisiones.
