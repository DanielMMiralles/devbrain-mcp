# React

## Resumen
Biblioteca declarativa basada en componentes para construir interfaces de usuario interactivas.

## Cuándo usar
- SPAs, dashboards interactivos, aplicaciones web dinámicas con alto estado.

## Gotchas & Buenas Prácticas
- Cuidado con re-renders innecesarios; aprovechar Server Components o memorización cuidadosa (useMemo, useCallback).
