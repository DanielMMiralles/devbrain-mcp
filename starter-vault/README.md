# 🧠 Tu Almacén Personal de Conocimiento — DevBrain

Bienvenido a tu propio cerebro digital.

Este almacén ha sido creado como una plantilla limpia para que organices tus ideas, notas técnicas y proyectos:
- **`00-INBOX/`**: Notas rápidas e información pendiente de clasificar.
- **`02-PROYECTOS/`**: Documentación de arquitectura y contexto de tus proyectos de software.
- **`03-CONOCIMIENTO/`**: Tus notas técnicas, patrones de diseño y aprendizajes de ingeniería.
- **`04-APRENDIZAJES/`**: Registro persistente de decisiones arquitectónicas y post-mortems.
- **`07-DIARIO/`**: Bitácora de trabajo diario.

Abre esta carpeta en **Obsidian** mediante la opción `Abrir carpeta como almacén` para empezar a construir tu red de neuronas.
