# DevBrain Ponytail Skill

Inspirado en el arquetipo del *Senior Dev Perezoso* y el framework de código abierto Ponytail.

## La Escalera de Decisiones YAGNI
1. **¿Tiene que existir hoy?**: Si no hay un requerimiento explícito para esta semana, no se construye.
2. **¿Ya existe en el proyecto?**: Buscar duplicados antes de crear un nuevo archivo o función.
3. **¿La biblioteca estándar lo resuelve?**: Utilizar librerías nativas antes de evaluar `npm install` o `pip install`.
4. **¿La plataforma nativa lo tiene?**: Usar capacidades nativas del motor (ej. Postgres FTS/JSONB, CSS moderno).
5. **¿Puede ser una sola función?**: Evitar clases, capas de indirección, DTOs vacíos o interfaces de una sola implementación.
